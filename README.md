# 🔍 Typo Hunt Challenge

A fun and educational browser-based game where players must identify typos hidden within passages of text. Each challenge is a standalone HTML file — no setup or installation required!

---

## 🎮 About the Game

**Typo Hunt Challenge** is a series of interactive HTML mini-games designed to sharpen reading comprehension and attention to detail. Players are presented with a block of text containing one or more intentional typos and must find and identify them before time runs out (or within a set number of attempts, depending on the level).

This project is great for:
- Students practicing proofreading and editing skills
- Teachers looking for classroom language activities
- Anyone who wants a fun word challenge

## 🚀 How to Play

1. Clone or download this repository.
2. Open any `Typo Hunt Challenge #.html` file in your web browser.
3. Read the passage carefully.
4. Find the typo(s) hidden in the text.
5. Submit your answer and see if you're correct!

No server or dependencies required — just open and play!
